> The initial purpose of this project is to have a web interface for [this repo](https://github.com/hasaki261/fadaSim).
> This project is only possible because of [enka.network](https://enka.network) and its good API.

fadaCLI is a terminal web simulator where you can navigate your Zenless Zone Zero profile using commands.

If you want to contribute to this project, you can download the repo, install the dependencies (`npm install`), and test locally (`npm run dev`).
